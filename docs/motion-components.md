# Motion components

Animated concept illustrations generated by the `lottie-motion` skill (`.claude/skills/lottie-motion`). Each one is a Lottie animation wrapped in a small React component.

## Layout

```
components/motion/
├── LottieMotion.tsx          shared player used by every animation (generated once, don't edit per animation)
└── examples/
    └── PacketRouting/        one folder per animation
        ├── index.tsx         the component you import
        ├── light.json        Lottie animation, light theme
        ├── dark.json         Lottie animation, dark theme
        └── source/build.mjs  the script that generated the JSON (not used at runtime)
```

The two JSON files are the animation. In the browser, `lottie-web` reads them and draws them as SVG. Each `index.tsx` holds what's specific to its animation (size, accessible label, poster frame, description), and `LottieMotion.tsx` holds everything else.

## Usage

```tsx
import PacketRouting from '@/components/motion/examples/PacketRouting';

<PacketRouting />
```

The component fills its parent's width and keeps its aspect ratio, so control its size through the parent (for example `className="max-w-[720px]"`).

Requires `lottie-web` as a dependency. The player loads it lazily (the light SVG build), and only the active theme's JSON is downloaded.

## Props

All optional. Each animation's `index.tsx` already sets sensible values.

| Prop | Default | Description |
|---|---|---|
| `theme` | `'auto'` | `'auto'` follows `html.dark` / `[data-theme]` / the OS setting; or force `'light'` / `'dark'` |
| `trigger` | `'inView'` | `'inView'` plays while at least 20% visible · `'hover'` plays while hovered · `'once'` plays once when first seen |
| `loop` | `true` | |
| `speed` | `1` | Playback speed multiplier |
| `posterFrame` | per animation | Frame shown before playback and to users with reduced motion |
| `label` | per animation | Accessible description (`role="img"`). Without it the animation is treated as decorative (`aria-hidden`) |
| `className`, `style` | | Applied to the wrapper |

## Behaviour

- **No layout shift**: the wrapper reserves the animation's aspect ratio before anything loads.
- **Performance**: it plays only while on screen and pauses when scrolled away or in background tabs.
- **Theme**: it swaps between `light.json` and `dark.json` live, keeping the current frame.
- **Reduced motion**: users with `prefers-reduced-motion` see the poster frame as a still image.
- **Intro + loop**: if an animation has `intro` and `loop` markers, the intro plays once, then the loop repeats.

## Changing an animation

Edit the values at the top of `source/build.mjs` (colours, sizes, speed, timing), then regenerate:

```bash
node components/motion/examples/PacketRouting/source/build.mjs /tmp/packet-routing
```

This writes new `light.json` / `dark.json` to that folder and prints a motion analysis (errors and warnings should be 0). Copy the two files into the component folder. Alternatively, ask Claude to make the change with the `lottie-motion` skill, which also renders and reviews the result.

## Adding an animation

Ask Claude (or delegate to the `lottie-motion-designer` agent) with the concept and where it will be used. The skill creates a new folder next to the existing ones and reuses the shared `LottieMotion.tsx`.
